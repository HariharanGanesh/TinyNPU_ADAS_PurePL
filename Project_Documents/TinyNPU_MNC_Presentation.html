Project Review

TinyNPU

An ASIC-Ready, High-Efficiency INT8 Systolic AI Accelerator for Deterministic Edge Vision

Architecture: Pure Hardware (Option A)

Target: Low-Power Real-Time Edge Inference

Problem Identification & Relevance

The Technical Bottleneck

  • Thermal Limitations: Edge AI (e.g., ballistics, drones) demands high FPS, but GPUs draw excessive power causing thermal throttling.
  • Software Jitter: Hybrid FPGA/SoC solutions rely on Linux/ARM drivers, introducing non-deterministic latency.
  • Lack of ASIC Fidelity: Many academic IP cores use software trickery, making them impossible to tape-out directly to physical silicon.

Why It Matters

Mission-critical vision systems require guaranteed clock-cycle accurate latency.

  • SWaP Constraints: Strict Size, Weight, and Power limits mean heatsinks are not an option.
  • Determinism: Unpredictable software interrupts cause missed frames in high-speed tracking.
  • Scalability: A pure RTL architecture can be instantly migrated from FPGA to a 7nm ASIC foundry.

Objectives & Expected Outcomes

Core Technical Objectives

  • Design a Weight-Stationary Systolic Array optimized specifically for INT8 quantized layers.
  • Eliminate all CPU overhead by building a processor-less verification architecture directly in hardware.
  • Apply Integrated Clock Gating (ICG) across isolated clock domains to strictly minimize dynamic switching power.

Expected Outcomes

  • Frequency: Sustain operational timing of 100+ MHz.
  • Efficiency: Cap total on-chip dynamic power below 200 mW.
  • Validation: Achieve 0 RTL syntax errors and 100% Verilog-2001 compatibility for ASIC portability.
  • Verification: Perform cycle-accurate pass/fail testing natively on silicon without software monitors.

Proposed Methodology

A rigorous, four-phase ASIC physical design and verification flow.

1. Deeply Pipelined RTL Design

Implement a 2-stage MAC pipeline and multi-stage requantization units to isolate combinatorial paths and ensure timing closure.

2. Pure Hardware Architecture

Replace software drivers with a physical BRAM Sensor Emulator streaming AXI data, fully bypassing ARM/PS components.

3. Power-Driven Synthesis

Utilize specific constraints (power_opt_design) to infer fine-grained ICG cells and force BRAM enable-pin optimizations.

4. On-Chip Silicon Verification

Flash the bitstream directly to the FPGA and monitor physical IO signals driven by a cycle-accurate hardware scoreboard.
